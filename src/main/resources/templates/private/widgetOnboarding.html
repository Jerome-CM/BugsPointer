Installer le widget - BugsPointer

Installation guidée

Installez BugsPointer sur votre site

Vérifiez votre domaine, copiez le script, puis ajustez le widget depuis un seul parcours.

Avant de commencer

Quel est le nom de votre entreprise ?

Ce nom nous aide à identifier correctement votre compte dans le dashboard et dans le suivi admin. Il pourra être modifié plus tard depuis votre compte.

Étape 1 : Domaine

Associer le site

Entrez le domaine public de votre site, par exemple exemple.fr. Vous pourrez ensuite installer le widget sur tout le site ou seulement sur certaines pages comme /blog.

Étape 2 : Installation

Copier le code

Choisissez une installation : bouton flottant automatique ou lien placé dans votre footer, menu ou contenu.

Option 1 : bouton flottant

!

Option 2 : lien sans bouton flottant

Signaler un bug

Avec l'option lien, le script charge uniquement la modal. Aucun bouton flottant n'est affiché.

Étape 3 : Vérification

Non validé ? Pour valider le domaine, BugsPointer doit détecter le script avec votre clé publique ou un lien personnalisé contenant cette clé sur une page accessible.

Vérifier le domaine

Indiquez l'url exacte d'une page où vous avez installé le script ou le lien personnalisé. BugsPointer l'ouvre en HTTPS et cherche votre clé publique.

Dernière étape

Personnaliser

Le plan Free permet d'installer le widget et de recevoir vos premiers rapports. La personnalisation complète est disponible avec Target.

Votre plan permet de modifier les couleurs, textes, position et taille du bouton.
