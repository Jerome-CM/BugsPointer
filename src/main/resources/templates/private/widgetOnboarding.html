Installer le widget - BugsPointer

Installation guidée

Installez BugsPointer sur votre site

Vérifiez votre domaine, copiez le script, puis ajustez le widget depuis un seul parcours.

Clé publique

pk_xxxxx

Étape 1 : Domaine

Associer le site

Entrez le domaine public de votre site, par exemple exemple.fr. Vous pourrez ensuite installer le widget sur tout le site ou seulement sur certaines pages comme /blog.

Étape 2 : Installation

Copier le script

Collez cette balise avant la fermeture </body> sur les pages où vous voulez afficher BugsPointer.

Étape 3 : Vérification

Non validé ? Pour valider le domaine, le script doit être détecté au moins une fois sur une page accessible du domaine. Ensuite, vous pouvez choisir où afficher le widget dans votre site.

Vérifier le domaine

Indiquez l'url exacte d'une page où vous avez installé le script. BugsPointer l'ouvre en HTTPS et cherche la balise contenant votre clé publique.

Besoin d'aide ?

Si l'installation bloque, contactez-nous avec votre domaine et l'URL testée.

contact@bugspointer.com

Dernière étape

Personnaliser

Le plan Free permet d'installer le widget et de recevoir vos premiers rapports. La personnalisation complète est disponible avec Target.

Votre plan permet de modifier les couleurs, textes, position et taille du bouton.
