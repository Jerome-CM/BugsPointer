Installer BugsPointer - script d’intégration

Installation BugsPointer

Ajoutez BugsPointer avec une seule balise script.

Plus de fichiers à télécharger, copier ou maintenir. Collez ce script dans votre site : la modal, le bouton, les styles et la configuration sont chargés automatiquement depuis BugsPointer.

Clé publique. Le script utilise data-public-key pour relier les rapports au bon projet.

Personnalisation centralisée. Couleurs, textes et position se règlent depuis votre compte.

Étape 1

Copiez le script

1. Coller

Ajoutez le script avant la fin du </body>.

2. Tester

Ouvrez votre site et cliquez sur le bouton BugsPointer.

3. Recevoir

Les rapports arrivent dans votre dashboard.

Étape 2

Configurer le widget

Depuis votre compte, vous pouvez modifier la couleur principale, le texte du bouton, le titre de la modal, le libellé du champ description et la position du bouton.

Personnaliser le widget Lire la documentation

Compatibilité

À prévoir côté site client

JavaScript externe

La plateforme doit autoriser une balise script venant de bugspointer.com.

CSP

Si une politique CSP existe, ajoutez script-src et connect-src pour BugsPointer.

Domaine

Votre domaine doit être renseigné dans le compte BugsPointer pour accepter les rapports.
