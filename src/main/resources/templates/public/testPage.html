Mode d'emploi

Comment tester BugsPointer sur cette page

Cette première partie explique le test. La zone à signaler commence juste après, dans le bloc “Zone de test”.

Étape 1

Ouvrez le widget

Cliquez sur le bouton flottant en bas à droite ou sur “Ouvrir le widget”.

Étape 2

Pointez une erreur

Dans la zone de test, sélectionnez une image cassée, un titre incohérent ou une erreur serveur.

Étape 3

Envoyez le rapport

Ajoutez une description et recevez le rapport de test par e-mail.

Zone de test

Les éléments ci-dessous sont faits pour être signalés

À partir d’ici, jouez le rôle d’un visiteur. Choisissez une erreur, ouvrez le widget, pointez l’élément concerné, puis décrivez le problème.

Erreur de contenu

Forfait maintenance 2049

Ce titre semble incohérent pour une page qui parle d’un essai actuel.

Erreur UX

Bouton principal absent

Un visiteur pourrait signaler qu’il manque un CTA ou qu’il ne sait pas quoi faire ensuite.
